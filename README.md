# Code Generation Review Notes

Practical notes on reviewing LLM-generated **Python** and **JavaScript** code.

## Purpose
This repository documents common patterns, failure modes, and evaluation criteria used when assessing code-generation outputs from large language models.

## Evaluation Focus
- Functional correctness
- Instruction-following accuracy
- Code safety and security considerations
- Readability and structure
- Edge-case handling

## Common Issues in Generated Code
- Logical errors that pass basic syntax checks
- Incomplete implementations
- Hallucinated functions or libraries
- Poor error handling
- Inefficient or overly complex solutions
- Failure to follow specific constraints in the prompt

## Review Approach
Responses are typically assessed against multi-dimensional rubrics covering correctness, safety, and adherence to instructions. Documenting recurring failure patterns helps improve consistency in evaluation.
